### ResumeAlign AI

**Resume-Tailor** is a specialized tool designed to bridge the gap between job descriptions and candidate profiles. By leveraging OpenAI's large language models, the application analyzes job requirements and optimizes an existing resume to highlight the most relevant skills, keywords, and experiences.

---

#### Key Features

* **Multi-Format Support:** Upload existing resumes in `.pdf` or `.docx` formats.
* **Context-Aware Optimization:** Select specific job tracks (Data Science, Financial Analysis, etc.) for targeted keyword injection.
* **Intelligent Synthesis:** Uses `gpt-4o-mini` to rewrite bullet points that align with specific Job Descriptions (JD).
* **Instant Export:** Generates and downloads a clean, professional `.docx` file ready for submission.
* **Secure API Handling:** Integrated with Streamlit Secrets for safe management of OpenAI credentials.
